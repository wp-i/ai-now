# 产品目标与迭代复盘

## 当前目标

为经常刷社媒、对 AI 有兴趣的普通中文读者做一个可直接浏览的科普站。读者在 PC 上看到一件实际产出后，应当能指出现在的 AI 做到了哪一步，以及这件作品在哪个具体条件下成立。首页最先给出值得停留的图像与视频，余下作品按产出方向进入各自页面。使用原作者的内容，保留模型或工具、出处和可核实的发布日期。

以前的目标把「15 秒混剪」写成了交付形式。用户所借鉴的是成片在短时间里集中呈现精彩内容的节奏。现在统一采用原作者的成片和原始素材。站内可以从原片的清楚段落开始静音预览，完整原片随时可看，单张图也可直接打开原尺寸。

## 当前进度和下个交付条件

- 11 月 23 日的基线是第 36 版。首页 11 件，五个专区共 29 件，分别为图像 8、视频 8、声音 5、游戏 4、网页 4。恢复第 33 版的红色手提包、机械果园和广告牌雪景作为下一轮图像比选的基准。
- 网站的公开展示由代码中的已审目录驱动。候选收集、原作核对和编排仍有人工步骤。当前样本适合说明具体能力，覆盖度继续由后续比选结果验证。
- 下一轮优先提高图像与视频的候选竞争，再扩充其他方向。每次拟更换首屏或增加重点能力，都记录同类近期候选、现有可见基准和替换依据。分类里出现材料过少或内容同质时，先查该方向仍缺少什么可直观看到的产出。
- 每次发布的完成条件是公开站 PC 的完整浏览路径通过，原作归属和页面显示一致，无失效媒体或误导性描述，且新材料经同类对比确实新增了观看价值。现网版本、已验证的行为、编辑判断和还待审的候选分别写在变更记录中。

## 这次对话里暴露的问题

| 问题 | 后续做法 |
| --- | --- |
| 多次在资讯门户、工具推荐、报纸和演示之间摇摆，首屏功能越做越多 | 以观看真实产出为主线。保留按产出分开的独立页面和有价值的媒体交互。删去只有少量重复结果的搜索、地理筛选、独立公告区、工具中转和重复展开。直接浏览，无需登录。 |
| 选了技术上能解释或已经拿奖的作品，读者第一眼仍看不出价值 | 先看 PC 上展示的成品，再看介绍、奖项、日期和模型名。画面或声音必须能独立成立。图像删层和拖拽只用于同一作品中一眼能看清的变化。研究样片需要和创作者原作一起比。 |
| 图像连续几轮先铺太多，随后又整体撤换，连访客认可的三件和有效交互都丢了 | 换版前保留优质基准，逐个决定换留。用明确的首页选取清单，专区增补和重排独立进行。首屏控制数量，第二层和专区补足不同能力。 |
| 把新鲜度当作日期标签，或为追求观感让数月前的作品长期占位 | 新近内容更可能推进边界。发现时优先近 30 天，通常回看近 60 天。视觉或制作水准相近时选更新的。较早基准继续占首页时记下近期对手、画面优势和复查原因。原帖、模型更新与转发时间分开。 |
| 采集偏向厂商，候选数量不够，同类缺少竞争 | 从创作者原帖、独立作品、公开平台、官方与开源项目交叉查找。X、YouTube、Bilibili、TikTok、Facebook、GitHub、Hugging Face 和公开赛事可用于发现。记录实际比看过的作品与无法打开的渠道，转发和重复变体归为一个候选。 |
| 文案写模型术语、品牌或运营提示，实物退到说明后面 | 用一项可见或可听的变化解释能力。只在必要时写工具名、参考输入和人工参与。一个原作入口通常足够。产品名、品牌标志和引导标题由用户明确决定。 |
| 把功能能打开当作交付，漏掉双分割线、鼠标焦点边框、无收益的点击和展示断层 | 以第一次进入站点的普通访客检查 PC 首屏和整页节奏，再键盘与鼠标走一遍。实际播放媒体、拖拽到两端、关闭和复原图层、验证来源与试玩。版本通过技术核验后仍要写清编辑判断和可感知的不足。 |
